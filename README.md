# ELEVEN

A retro-style football game by Enkel Design — touch-first, initially targeting iPhone and iPad.

**Status:** project startup. The engine and platform are not decided yet; Unity 6 is the leading hypothesis and an engine spike will settle it in ADR-0001. No football is implemented before then.
